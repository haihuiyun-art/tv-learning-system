# 题库制作与导入指南

家长可以用 AI 按指定格式生成题库，也可以通过文本编辑器自行制作。题库保存在电视端应用私有目录，不需要云端账号。

## 1. 抽题方式

- 可以把语文、数学、英语、科学或不同学习进度分别保存为多份 JSON 文件。
- 只有“已启用、无错误且含有效题目”的文件参与抽题。
- 系统把所有启用文件的题目合并后随机抽取，不是每次只使用一个文件。
- 抽题时尽量排除上一题；只有一道可用题时无法避免重复。
- 不同文件可以使用相同的原始 `id`，系统通过内部文件 ID 区分。
- 同名导入会更新原文件并保留启用状态；删除全部文件后，内置示例不会自动恢复。

## 2. 数量与大小限制

| 项目 | 限制 |
| --- | --- |
| 单个 JSON 文件 | 最大 4 MB |
| 单份文件题目数 | 1～500 题 |
| 文件数量 | 最多 50 个 |
| 全部文件合计 | 最多 5000 题 |
| 每题选项 | 2～6 个非空字符串 |
| 正确答案 | 每题只有一个 |

## 3. JSON 格式

顶层必须是 JSON 对象：

| 字段 | 要求 |
| --- | --- |
| `formatVersion` | 固定为数字 `1` |
| `version` | 字符串，用于标记这份题库的版本 |
| `questions` | 题目数组，每份 1～500 题 |

每道题包含：

| 字段 | 要求 |
| --- | --- |
| `id` | 字符串，同一次导入内唯一，例如 `math-001` |
| `grade` | 年级，例如 `一年级`、`三年级` |
| `subject` | 学科，例如 `数学`、`语文`、`英语` |
| `topic` | 知识点，例如 `20以内加法` |
| `difficulty` | 只能是 `简单`、`中等`、`困难` |
| `stem` | 题干 |
| `options` | 2～6 个非空字符串选项；判断题也使用两个选项 |
| `answer` | 正确选项下标，**从 0 开始**：A=0、B=1、C=2、D=3 |
| `explanation` | 简洁解析 |
| `source` | 来源标记，例如 `AI生成`、`家长录入` |

完整模板位于 [`app/src/main/assets/parent/questions-template.json`](../app/src/main/assets/parent/questions-template.json)，也可以在家长网页的题库页下载。

示例：

```json
{
  "formatVersion": 1,
  "version": "二年级数学-2026-01",
  "questions": [
    {
      "id": "math-001",
      "grade": "二年级",
      "subject": "数学",
      "topic": "乘法口诀",
      "difficulty": "简单",
      "stem": "7 × 8 = ?",
      "options": ["54", "56", "63", "48"],
      "answer": 1,
      "explanation": "七八五十六，所以答案是 56。",
      "source": "AI生成"
    },
    {
      "id": "math-002",
      "grade": "二年级",
      "subject": "数学",
      "topic": "基础判断",
      "difficulty": "简单",
      "stem": "10 是偶数。（判断题）",
      "options": ["正确", "错误"],
      "answer": 0,
      "explanation": "10 能被 2 整除，所以是偶数。",
      "source": "AI生成"
    }
  ]
}
```

注意：第二题 A 选项“正确”的下标是 `0`，所以 `answer` 为 `0`；第一题 B 选项“56”的下标是 `1`，所以 `answer` 为 `1`。不要从 1 开始编号。

## 4. 可直接交给 AI 的制题提示词

先下载或复制题库模板给 AI，再按实际情况修改下面的提示词：

```text
请为小学二年级学生制作一份数学选择题题库，共 30 题，范围为 100 以内加减法和乘法口诀，难度以简单为主，少量中等。

请严格输出一个 UTF-8 编码的 JSON 对象，不要使用 Markdown 代码围栏，不要输出额外解释。顶层必须包含：
- formatVersion：固定为数字 1
- version：字符串
- questions：题目数组

每题必须包含 id、grade、subject、topic、difficulty、stem、options、answer、explanation、source。
- id 在同一文件内唯一。
- grade 写“二年级”，subject 写“数学”，topic 填具体知识点。
- difficulty 只能是“简单”“中等”“困难”。
- options 为 2～6 个非空字符串，正确答案只能有一个。
- answer 是从 0 开始的正确选项下标，不是选项字母，也不是从 1 开始的序号。
- explanation 用孩子能理解的一句话说明解题过程。
- source 写“AI生成”。

生成后请再次逐题检查：题干无歧义、计算和答案正确、answer 下标与正确选项一致、所有 id 唯一、JSON 语法有效。
```

英语、语文、科学或其他年级只需修改学科、范围、题量和难度。建议按学科或学习进度拆成多份文件，而不是制作一个超大文件。

**AI 可能生成错误答案或超龄内容。导入前必须由家长抽查题干、答案和解析，不能仅凭 AI 自检直接交给孩子使用。**

## 5. 导入步骤

1. 让 AI 将结果保存为 UTF-8 编码的 `.json` 文件。
2. 在与电视相同的可信 Wi-Fi 下打开家长网页并登录。
3. 进入“题库”页面，在“添加或更新题库”中选择一份或多份 JSON 文件。
4. 点击“逐个读取并检查文件”，核对每份文件的题目数量和内容预览。
5. 确认后逐份上传；只有所有检查通过的文件才应导入。
6. 在题库文件列表确认启用状态、有效题数和错误摘要。
7. 实际完成几次答题和冷却换题，检查是否按预期跨文件抽题。

上传或更新不会自动清除其他题库。损坏文件会被隔离并显示错误，不应把“文件存在”误认为“题目可用”。
